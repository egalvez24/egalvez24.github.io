Key Concepts

HTTP is a key foundation of the World Wide Web that paved way for expansion of what we use today and for upcoming advancements. HTTP is known as the “request-response” language. A series of information being transferred back and forth between the browser (referred to as client) and browser-server. Typically, it's the communication we initiate with the browser (Chrome, Safari, Firefox, etc.) that sends an HTTP request to the server that's hosting our content. Then the server responds with an HTTP back to our browser.
