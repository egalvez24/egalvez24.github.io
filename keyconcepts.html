Header Compression The practice of small files loading quicker than larger ones. This atrribute eliminates a few bytes from HTTP packets to load faster.

Multiplexing The attribute of a client requesting information and the web server responding with multiple streams of data all at once to the client. Instead of sending data on by one like. A unique feature is the involvement of developers assigning each data stream as weighted value. (These unique weighted values tell which data to render first.)

APIs An HTTP API (Representational State Transfer) is any API that uses HTTP for communication between the client and web server. They don't follow a design pattern. Examples - the REST API. This is API uses the foundation of HTTP requests.

Keepalive Connections keepalive connections. A way to reduce latency of a HTTP request. The basis of this approach was to allow the client create another request without having to end the connection. This can be overridden by Connection Close.

QUIC was not mandatory since HTTPs already made sites encrypted. However, this option optimized security when optional. This feature also prevented attacks like DoS and Man-in-the-Middle. Originally developed by Google.
