Breakdown of HTTP

HTTP consist more than just requesting and responding. HTTP needs various layers to come together for it to function properly. HTTP isn't just a block of saying “I want this content”, but it consist of a header and body with specific detail in what the client is looking for. Going one step further, HTTP is also broken down into methods used by many. In addition, there are 5 versions of HTTP:

  1. HTTP 0.9
  2. HTTP 1.0
  3. HTTP/1.1
  4. HTTP/2
  5. HTTP/3

OVERVIEW OF HTTP

HTTP (Hypertext Transfer Protocol) is a key foundation of the World Wide Web that paved way for expansion of what we use today and for upcoming advancements. HTTP is known as the “request-response” language. A series of information being transferred back and forth between the browser (referred to as client) and browser-server. Typically, it's the communication we initiate with the browser (Chrome, Safari, Firefox, etc.) that sends an HTTP request to the server that's hosting our content. Then the server responds with an HTTP back to our browser.
