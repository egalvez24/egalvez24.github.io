Humble Beginnings of HTTP - "0.9"

HTTP was first initiated by Tim Berners-Lee in 1991 at CERN as a proposal to just transfer hypertext documents. For this idea to be completed, the early developers had to create a new TCP/IP application protocol. This version would then pick up the name “HTTP 0.9”. (This wasn't an official title). This version only had a one-line connection. From establishing a connection between the HTTP client and HTTP server using only TCP (Transfer Control Protocol). This client of HTTP also used the GET method to request; however, the response came back with no header, metadata, and with the connection closing. The response was only an HTML document, nothing else.

This version of HTTP “0.9” was very limited and simple. The early developers however sought to make “0.9” bigger than intended. They were preparing to unleash the biggest project of the 20th century for the World Wide Web. This push of the new HTTP would meet expectations of the growing web and execute quicker than just a simple one-line connection.

HTTP 1.0

HTTP 1.0 was a huge success. From the skeletal foundation of 0.9, the web was entering a new era of protocols and document transfers. From this success, groups started to implement their own protocols and even lists on how to maneuver HTTP 1.0.

Tim Berners-Lee and his team at CERN had paved the way for the future introducing HTTP 1.0. Published in 1996, this version of HTTP had big improvements from its predecessor. This version of HTTP 1.0 introduced a wide variety of options: More capable web servers and clients, opening doors to other media than just hypertext documents, and even retain backwards compatibility with “0.9”. Other than just hypertext links, it had adopted MIME, (Multipurpose Internet Mail Extensions) so the ability to request videos, images, stylesheets were new to the public. This led to the expansion of the web and more people started using it. This version also introduced request and response headers and established more methods like DELETE and POST.
